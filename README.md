# Sistema de Cadastro de Alunos

##  Status do Projeto

- Projeto em desenvolvimento

##  Tecnologias Utilizadas

Este projeto foi desenvolvido utilizando as seguintes tecnologias abordadas no curso:

- Java (JDK 17+)
- Swing (Interface gráfica)
- JDBC (conexão com banco de dados)
- MySQL (banco de dados)
- Git & GitHub (controle de versão)

##  Time de Desenvolvedores

- Eduardo Goulart Soares

##  Objetivo do Software

O sistema tem como objetivo realizar o **cadastro e a visualização de dados de alunos**, possibilitando o controle de informações como:

- Nome do aluno
- Matéria
- Média final
- Quantidade de faltas

Além disso, o sistema permite a **visualização em formato de tabela com filtro dinâmico**, tornando a busca por alunos mais rápida e eficiente.

##  Funcionalidades do Sistema

- Cadastro de alunos com campos obrigatórios
- Listagem de alunos cadastrados
- Filtro dinâmico por nome na tabela de alunos
- Interface gráfica desenvolvida com Java Swing
- Armazenamento dos dados em banco de dados MySQL
- Versionamento com Git e GitHub
